## 设计决策汇总

| 维度 | 决策 | 理由 |
|------|------|------|
| 目标用户 | 业务决策型 | 产品经理、采购、CTO，需要引导和解释 |
| 视觉风格 | 专业商务型 | 类似 AWS 控制台，简洁、数据密集、强调可信度 |
| 整体布局 | 双栏固定式 | 左输入 400px + 右结果自适应，因果关系清晰 |
| 交互模式 | 单页全览式 | 所有参数一页展示，便于反复调参对比 |
| 方案对比 | 表格对比式 | 行是费用项、列是方案，含单价/用量/费用三元组 |
| 敏感度分析 | 滑块交互式 | 拖动即实时显示成本变化 |
| 移动端 | 桌面优先 | 暂不考虑移动端适配 |

## 一、整体布局

```
┌─────────────────────────────────────────────────────────────┐
│  Logo    [计算器]  [评估历史]  [定价管理]      [登录/用户]  │
├────────────────────────┬────────────────────────────────────┤
│                        │                                    │
│   📝 参数输入区         │   📊 结果展示区                    │
│   (固定宽度 400px)      │   (自适应剩余宽度)                 │
│                        │                                    │
│   - 预设场景选择        │   - 费用汇总卡片                   │
│   - 功能维度折叠面板    │   - 方案对比表格                   │
│   - 技术维度折叠面板    │   - 费用构成图表                   │
│   - 价格维度折叠面板    │   - 敏感度分析面板                 │
│                        │                                    │
│   [导出] [分享] [保存]  │                                    │
│                        │                                    │
└────────────────────────┴────────────────────────────────────┘
```

**核心设计理念：**
- 左侧输入、右侧输出：符合从左到右的阅读习惯，因果关系清晰
- 左栏固定宽度：保持输入控件紧凑，避免表单过于分散
- 右栏自适应：充分利用大屏空间展示图表和对比表格
- 折叠面板：三类维度默认展开功能维度（最常调整），技术/价格维度可折叠

## 五、全局交互设计

### 5.1 参数验证与错误提示

```
┌─────────────────────────────────────┐
│  设备数量                           │
│  [   -50    ] 台        ⚠️          │
│  └─ ❌ 设备数量必须在 1-100000 之间 │
└─────────────────────────────────────┘
```

- 实时验证，输入离焦后立即校验
- 错误字段红色边框 + 下方错误提示
- 存在验证错误时，结果区显示占位提示

### 5.2 计算状态指示

```
正常状态：   💰 成本估算    实时计算 ●   ← 绿色圆点
计算中状态： 💰 成本估算    计算中 ◐    ← 旋转动画
错误状态：   💰 成本估算    参数错误 ○   ← 灰色圆点
```

## 七、实施建议

### 技术选型建议

| 层面 | 推荐方案 | 理由 |
|------|----------|------|
| 前端框架 | React + TypeScript | 类型安全，组件化，生态丰富 |
| 状态管理 | Zustand 或 Jotai | 轻量级，适合表单+实时计算场景 |
| UI 组件库 | Ant Design | 专业商务风格，表格/表单组件完善 |
| 图表库 | ECharts 或 Recharts | 饼图、柱状图支持良好 |
| 表单验证 | Zod + React Hook Form | 类型安全的实时验证 |

### 优先级建议

1. **P0 - 核心计算流程**: 参数输入 → 实时计算 → 结果展示
2. **P1 - 方案对比**: 对比表格 + 推荐逻辑
3. **P2 - 可视化增强**: 饼图 + 敏感度分析
4. **P3 - 辅助功能**: 导出/分享/历史记录
